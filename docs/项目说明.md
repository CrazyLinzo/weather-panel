## 本地运行

### 方式一：直接打开 (最简单)
双击项目根目录的 `index.html` 或 `fieldsight.html` 用浏览器打开即可。

### 方式二：本地服务器 (推荐)
```bash
cd 天气看板demo
python -m http.server 8080
```
然后访问：
- http://localhost:8080/fieldsight.html（研究报告风完整版）
- http://localhost:8080/index.html（暗色主面板）

### 方式三：使用 Node.js
```bash
npx serve .
```

- **8大品种**：棕榈油、棉花、玉米、大豆、小麦、咖啡、白糖、稻谷
- **107个产区**：覆盖中国、美国、巴西、阿根廷、马来西亚、印尼、泰国、印度、澳大利亚、俄罗斯、乌克兰、加拿大、埃塞俄比亚、哥伦比亚等
- **海洋指数**：ENSO、PDO、NAO、IOD
- **预报时效**：37天回溯 + 7天预报
- **中国天气**：NMC降水预报 + 土壤墒情 + 最高气温预报 + 逐时气温 + 强对流/雷达/卫星
- **美国天气**：NOAA WPC/SPC/CPC/NWS/USDM + GEFS集合预报
- **台风监测**：中央气象台台风网 + JTWC 可视化路径

## 数据来源

| 数据层 | 来源 | 更新方式 |
|--------|------|----------|
| 实时气象 | Open-Meteo API | 每次页面加载自动拉取 |
| 历史气候 | Open-Meteo Archive API | 按需拉取 (季节性图) |
| 美国天气图 | NOAA WPC/SPC/CPC/NWS/USDM | 官方外链，每日自动更新 |
| GEFS预报 | World Ag Weather | 运行ID自动探测 |
| 中国预报图 | 中央气象台 (NMC) | URL时间戳自动探测（多维度） |
| ENSO/海洋指数 | IRI/NOAA/BOM/JMA | 人工定期维护 JS 文件 |
| 农业新闻 | 多来源精选 | 人工定期维护 JS 文件 |
| 台风监测 | 中央气象台台风网 + JTWC | 官方外链 |
| 特殊天气事件 | 官方气象机构汇总 | 人工定期维护 JS 文件 |

## 注意事项

1. 从中国大陆访问时，NOAA 图片和 Open-Meteo API 可能需要科学上网
2. Open-Meteo 免费 API 限制 10,000次/天
3. ENSO/海洋指数/新闻/特殊事件为静态数据，需手动更新 JS 文件
4. 策略建议仅供研究参考，不构成投资建议
