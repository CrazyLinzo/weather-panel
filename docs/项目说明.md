## 本地运行

### 方式一：直接打开 (最简单)
双击项目根目录的 `index.html` 或 `fieldsight.html` 用浏览器打开即可。

### 方式二：本地服务器 (推荐)
```bash
cd 天气看板demo
python -m http.server 8080
```
然后访问：
- http://localhost:8080/fieldsight.html（研究报告风完整版）
- http://localhost:8080/index.html（暗色主面板）

### 方式三：使用 Node.js
```bash
npx serve .
```

## 更新流程

数据分两层：⚡**自动层**(GitHub Actions 每日 00:17 生成 `data/*.js`) 与 **人工层**(`fieldsight-data.js` 手写)。前端对自动层做 `typeof` 守卫——文件缺失时自动回退人工层，不会破页面。

### 每日自动(无需操作)
`.github/workflows/daily-fetch.yml` 每日 00:17 自动跑并按序提交数据、触发 Pages 重建：
1. `scripts/fetch_official.py` — 海洋指数 9 源 + midrange 快照 + 台风
2. `scripts/parse_midrange.py` — 中期公报 → `data/cn-outlook.js`
3. `scripts/fetch_usda.py` — USDA → `data/crop-progress.js`
4. `scripts/probe_events.py` — 台风 → `data/event-candidates.js`(候选，不直接展示)
5. `scripts/probe_sources.py` — 图源时效 → `data/img-sources.js`

你要做的：不用做。如需临时重跑，在仓库 Actions 页对 `Daily official data fetch` 点 **Run workflow**。

### 每周人工维护(改 `fieldsight-data.js`)
自动层管数值事实；以下仍是人工内容，每周更新时手动编辑：
- 「拾壹」north/south **影响推演**(玉米/大豆/棉花/白糖的 driver/impact/mech/watch)
- `SPECIAL_EVENTS` 人工事件(美国墒情、欧洲减产等)
- `STRATEGY_NOTE` / `AG_NEWS`(策略与新闻精编)
- 各产区行的分析文本(美国三行已自动，其余手工)

改完推送即可，Pages 自动重建：
```bash
git add fieldsight-data.js
git commit -m "更新XXX"
git push
```

### 台风候选审核(可选)
每天 Actions 生成 `data/event-candidates.js`(活动台风候选)。想让它们上页面：
```bash
python scripts/review_events.py        # 逐个 y/n/s/q
# 或 python scripts/review_events.py --all
git add data/special-events.js
git commit -m "审核台风事件"
git push
```
不审核则自动台风事件不显示；事件按 date 3 天过期自动移除。

## 注意事项

1. 从中国大陆访问时，NOAA 图片和 Open-Meteo API 可能需要科学上网
2. Open-Meteo 免费 API 限制 10,000次/天
3. 数值类数据(海洋指数/USDA/中期公报/台风)由 GitHub Actions 每日自动生成；分析推演与人工事件仍需手动编辑 `fieldsight-data.js`
4. 策略建议仅供研究参考，不构成投资建议
